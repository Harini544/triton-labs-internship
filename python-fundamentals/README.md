## How I should use this folder

1. Read the explanation.
2. Run the examples.
3. Modify the examples.
4. Solve the practice questions without looking at solutions.
5. Test the program from the terminal.
6. Review mistakes.
7. Move to the next topic only after understanding the current one.

## How to run a Python file

Open a terminal in this folder and run:

```bash
python 01_lists.py
```

Replace `01_lists.py` with the file you want to practice.
